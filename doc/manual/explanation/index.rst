Explanation
===========

Background: how zdocs works and why it is built the way it is, for readers who
want to contribute to zdocs rather than just using it.

Start with :doc:`architecture/index` for the shape of the engine as a whole.
The pages after it take one mechanism each and follow it end to end. The
guidelines pages state the norms this project holds itself to, and
:doc:`decisions/index` is the historical record: every architectural decision,
dated, with the situation that forced it.
